# Nuxt Template

This template is an extension of the default nuxt starter template.
It enriches it with

- Nuxt UI (with some minimal default)
- i18n
- spellchecking
- eslint config
- typechecking
- Lighthouse checks in CI (every category has to score 100, see `lighthouserc.json`)

It uses `pnpm` as package manager.
`SSR` is deactivated.

Look at the [Nuxt documentation](https://nuxt.com/docs/getting-started/introduction) to learn more.
